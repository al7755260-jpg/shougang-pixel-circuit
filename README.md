# 首钢园像素大奖赛

用 Three.js 制作的体素赛车游戏，在首钢园的未来景观中比赛。

**[点击开始游戏](https://al7755260-jpg.github.io/shougang-pixel-circuit/)** · [版本与下载](https://github.com/al7755260-jpg/shougang-pixel-circuit/releases)

## 体验版内容

- 10 款不同风格的赛车，独立转向与旋转轮胎，开赛前 3、2、1 特写运镜。
- 6 圈比赛、无限练习、最多 6 人好友房间；空位由 AI 补齐，房主随时发车。
- 根据实景扫描转换的体素首钢园，物理材质、太阳光影、像素云、星球和飞船。
- 漂移冲刺、金币与道具、末位涡轮、漫画表情，以及机器人导弹、弹坑和追尾翻车效果。
- 导弹命中或驶入仍存在的弹坑会使车辆焚毁，车体焦黑并散落轮胎与碎片，1.5 秒后复位。坑的危险范围随坑缩小，消失后恢复通行；单人和联机使用相同的存续时间与判定。
- 像素金刚沿赛道追逐赛车，短暂预警后抓起并抛出车辆；护盾可抵挡，抛出后 1.5 秒复位。单人及好友房间使用同一套判定。
- 奶奶会在斑马线处来回过街；撞到后，她坐在车前拦车 1 秒，起身让开后即可继续。可以提前避让，单人和联机均支持。
- PC 键鼠和手机竖屏双拇指操作；自动调节内部渲染分辨率，手机默认采用流畅画质。
- 手机左侧十字方向键，右侧独立刹车与漂移；开场运镜平滑接入跟车镜头，并移除能量冲击文字弹框。
- 音乐与音效独立调节，BGM 播放与比赛暂停联动。Tokyo Drift 音频尚待提供，本版本暂不含歌曲。

首次进入需下载园区与赛车资源，请等待加载完成。设置中可以切换体素精度与光影质量；较慢设备建议使用流畅光影与像素体素精度。公开版包含两档体素园区，原始高斯扫描及 Blender 工程不在发布包内。

## 操作

| 操作 | PC |
| --- | --- |
| 加速 / 刹车倒车 / 转向 | W / S / A、D，或方向键 |
| 漂移并蓄能，松开冲刺 | 空格 + 转向 |
| 使用道具 / 回到赛道 | E / R |
| 镜头切换 / 全屏 / 隐藏界面 | C / F / H |
| 环绕 / 拉近拉远 / 镜头复位 | 鼠标拖动 / 滚轮 / 双击 |
| 暂停或打开菜单 | Esc |

手机竖屏：左侧十字键上前进、下刹车倒车、左右转向，按住左上或右上斜向区域可同时加速转弯；右侧独立刹车、漂移按钮，配合转向按住漂移蓄能，松开释放冲刺。道具按钮独立，点击排名可短暂展开赛况，拖动空白区域可环视。切换镜头和复位在暂停菜单内。支持浏览器“添加到主屏幕”；这不代表离线可用。

## 和朋友一起玩

进入“多人联机”，选择赛车后创建房间，点击“复制邀请”。好友打开链接、选择自己的赛车后会自动加入该房间。房主点击“开始比赛”即可发车，无需等满 6 人。房间关闭、已满或正在比赛时会显示对应提示。

**当前公开体验版的多人服务由开发者的电脑通过临时 Cloudflare 隧道提供。电脑或隧道关闭时，多人房间不可用；GitHub 上的单人游戏仍可访问。** 隧道重启后，请使用房主新复制的邀请链接。网络延迟和可用性取决于双方网络、隧道和主机带宽。

GitHub Pages 只托管前端静态资源，无法运行 WebSocket 房间服务器。房间是临时内存数据，服务器重启不会保留比赛。玩家不需要注册账号，请勿在昵称或房间名中填写私人信息。

## 本地运行

需要 Node.js 22 或更新的兼容版本。

```sh
npm ci
npm test
npm run build
npm start
```

打开终端显示的地址，默认 `http://127.0.0.1:4192/`。同一局域网的朋友可使用房间内提供的局域网地址。Windows 也可使用 `启动游戏.cmd`；首次运行应先执行上述安装与构建命令。

Windows 使用 `启动外网联机.cmd` 可建立临时外网入口。分享程序保持运行期间才可联机；它不会设置开机自启。`public-client.json` 配置公开游戏页面地址，邀请会附带当前隧道入口。

## 发布与独立服务器

```sh
npm run build:public
```

生成的 `dist-public` 可发布为静态网站。本仓库的 GitHub Actions 会测试、构建并部署到 Pages。项目子路径在 `vite.config.js` 配置；部署至不同仓库时需同步修改。`public/runtime.json` 的 `multiplayerOrigin` 指向支持 HTTPS/WSS 的房间服务。

独立服务器可直接执行 `node server.mjs`，或使用附带 Dockerfile。设置 `PORT`（容器默认 8080）和 `GAME_PUBLIC_PAGE`（允许连接的游戏页面完整 HTTPS 地址）。反向代理需支持 WebSocket，服务路径为 `/multiplayer`，健康检查为 `/api/health`。若设置 `GAME_PUBLIC_ORIGIN`，邀请链接可使用该服务的公开地址。

当前房间保存在单个进程中；多个副本不能直接共享房间。部署到自有服务器后更新 `public/runtime.json` 并重新发布前端，即可摆脱开发者本机在线的限制。
